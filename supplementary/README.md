# supplementary — material referenced from the article

The article points the reader to "the supplementary material" in four places.
Rather than duplicate files here, this folder holds an index that maps each
of those references to the file in this release that answers it.

See `INDEX.md`.

The index also records two things that are easy to get wrong when reusing
this release: which archive folder corresponds to the numbers printed in the
article, and why the hypervolume columns of the three categorical-ablation
tables are not comparable with one another.
