# data/B2 — controlled mixed-variable ablation instances

Problem data for the six controlled mixed-variable reformulations used in the
categorical-neighborhood ablation (Fixed / CC-static / CC-DNR / Full).

Expected contents:

- instance definitions for the six pairs (DPAM1-Mix, FES1-Mix, QV1-Mix,
  DTLZ2-Mix, ZDT3-Mix, ZDT1-Mix);
- the discrete grids `V_i` and categorical encodings `K_i` for each instance;
- any index file documenting how the instances were generated.

The underlying continuous and mixed benchmark suites are archived separately in
`MOO_Prob_Matlab` (https://doi.org/10.5281/zenodo.20783714); include here only
what is specific to the reported ablation.
