# results/archives — final nondominated archives

The final nondominated list of every reported run, in the form used to compute
the published metrics.

Expected contents:

- the MORAP-NM run archives for the Fixed, CC-DNR and Full poll variants
  (e.g. `pilot_fixed_run1.mat`, `pilot_fixed_run2.mat`, `pilot_fixed_run3.mat`);
- the B2 ablation archives (e.g. `b3b_results.mat` or per-variant equivalents).

Every table in `results/metrics/` must be recomputable from these archives.
